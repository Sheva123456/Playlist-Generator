# Playlist-Generator 

Creating music playlists is a common activity for studying, exercising, traveling, and more. However, choosing songs that both fit within a specific time limit and match the listener’s preferences can be difficult and time-consuming. Each song has a duration and varies in enjoyment or preference level, making it challenging to manually select the best combination of songs. The goal of this project is to design and implement a music playlist generator that utilizes the knapsack problem to maximize the user’s enjoyment score within a set time limit.  

*How to run*
- install customtkinter
- run gui2 to start the app
